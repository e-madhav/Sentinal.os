What Is SENTINAL.OS?
SENTINAL.OS is an AI-powered adversarial machine learning demonstration platform. It showcases how neural networks can be fooled by invisible pixel-level attacks — and how a trained UNet purifier can neutralize those threats in real time. Upload any face image to see the system in action across three phases: baseline analysis, attack simulation, and threat neutralization.

How To Use The System
01
Upload Face Image

// MONITOR GUIDE
Understanding The Two Displays
MONITOR 1 — CLEAN REF
Always shows the original, unmodified face crop and the classifier's honest baseline prediction (REAL or DEEPFAKE).
MONITOR 2 — HACKER MODE
Displays the adversarially perturbed image. The noise is invisible to humans but causes the AI to misclassify.
MONITOR 2 — DEFENSE SHIELDS
Shows the purified output. The UNet has removed adversarial perturbations and the classifier correctly identifies the subject again. Toggle between modes after a single scan — no need to re-upload.
